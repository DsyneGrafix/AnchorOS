# Sprint 4 Verification Checklist

## Package safety

- [ ] ZIP SHA-256 matches the supplied digest.
- [ ] `SPRINT4-PACKAGE-MANIFEST.txt` hashes match extracted files.
- [ ] No SQLite database/WAL/SHM, uploaded evidence, backup, cache, or customer
      data is present.
- [ ] `api` and `spatial-opportunity-engine` are siblings.
- [ ] Sprint 3 source, database, and evidence store are backed up.

## Automated verification

- [ ] API suite reports 27 tests and `OK`.
- [ ] Existing S.P.A.T.I.A.L. engine suite reports 8 tests and `OK`.
- [ ] `python3 -m py_compile anchorintel_api/*.py tests/test_api.py` succeeds.
- [ ] `bash -n start-anchorintel.sh` succeeds.

## Reference provenance chain

- [ ] `OI-000001`, `EV-000001`, and `KR-000001` remain visible.
- [ ] `AS-000001` is generated by the installed service rather than inserted as
      a fixed result object.
- [ ] Assessment detail links `AS-000001` to `KR-000001` and traces
      `EV-000001` revision/hash metadata.
- [ ] Reference output is Hold, 33.2/100, Low engine evidence confidence, and
      High risk under the bounded conservative adapter.
- [ ] The UI shows engine v0.1.0 and adapter v1.0.0.
- [ ] Gate results, assumptions, explanation, warnings, evidence trace, and
      replay hash are visible.
- [ ] The bounded-run notice disclaims internet, external AI, evidence creation,
      and independent verification.

## Determinism and replay

- [ ] Rerunning identical OI/EV/KR/engine/adapter inputs produces identical
      structured output and replay hash.
- [ ] Replay reports `match: true` and equal stored/recomputed hashes.
- [ ] Restart preserves the assessment and successful replay.
- [ ] Execution timestamp and `AS-*` ID do not change replay identity.

## Staleness and lifecycle

- [ ] Editing the opportunity rejects the old review for a new assessment.
- [ ] Editing or archiving evidence rejects the old review.
- [ ] A superseded review is rejected.
- [ ] A changed opportunity/evidence/review/module/engine/adapter condition makes
      a prior assessment stale.
- [ ] A current assessment completes `Run S.P.A.T.I.A.L.`.
- [ ] A stale assessment returns that stage to pending.
- [ ] Executive Opportunity Dossier and Archive Results remain pending.

## Migration and audit

- [ ] Existing Sprint 3 rows and uploaded files remain intact.
- [ ] Legacy assessment rows remain readable and marked `legacy`.
- [ ] New assessment columns and the kind/opportunity index exist.
- [ ] Audit includes `assessment.spatial_completed`, `assessment.replayed`, and
      first `assessment.stale` detection without claiming immutable storage.
